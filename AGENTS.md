# Antigravity Project Rules & Guidelines

## 🌐 UI/UX Language Requirement (Strict)
- **English ONLY**: All UI/UX elements, labels, buttons, descriptions, tooltips, progress updates, status messages, dialog cards, and interactive responses across both the **Desktop App (React Frontend)** and **Telegram Remote Control Bot** MUST be written in **English**.
- **No Indonesian**: Do NOT use Indonesian text or descriptions anywhere in the user-facing user interface or bot responses.
- **Telegram Bot Keyboard**: Standardize all Telegram Bot keyboard button labels to English:
  - `🔍 Check Webtoon`
  - `📚 Catalog`
  - `⬇️ Download`
  - `📊 Status`
  - `⏹ Stop`
  - `📂 Output Folder`
  - `🕘 History`
  - `⚡ Benchmark`
  - `⚙️ Settings`
  - `ℹ️ Help`
